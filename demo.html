Queue Cue demo chat

This page pretends to be a website with a Tawk.to live chat, so you can see Queue Cue's alerts without waiting for a real agent. The buttons play the part of the agent. Nothing here is sent anywhere: the chat lines are made up, and only this browser keeps them.

How to try it

  1. Install Queue Cue from the Chrome Web Store. On this page, click the Queue Cue icon in Chrome's toolbar (if you don't see it, click the jigsaw-piece Extensions button first), click Watch chats on this site, allow access, then refresh this page.
  2. Click Agent replies in 10 seconds, then switch to another tab before the countdown ends. A notification "Agent replied on this website" appears. Click it to come back here.
  3. Try the same while you stay on this tab: no notification, because you're already looking at the chat.
  4. If you get a notification and don't come back, Queue Cue reminds you once a few minutes later (the time is in Queue Cue's settings). Coming back means clicking the notification, switching to this tab from another tab, or clicking Send a message as you.
  5. Click End chat when you're done, so Queue Cue stops keeping the computer awake.

No notification? Check that your computer lets Chrome show notifications (Do Not Disturb or Focus can hide them).
